# Proposals

A proposal is a design document written before a feature or change is built. It
describes the problem, the design, and the alternatives that were considered.
Proposals are design history for people working on gritz; they describe the
design at the time it was written, not necessarily how gritz behaves now. For
how gritz works today, see the rest of these docs.

Each proposal has one of three statuses:

- **Draft**: under discussion or not yet built.
- **Implemented**: built and shipped. The code may have moved on since.
- **Rejected**: considered and not pursued. The proposal records why.
