# AttrDef

AttrDef is an event attribute a routing rule can have a condition on.

## Fields

| Field | Type | Description |
| --- | --- | --- |
| `key` | `string` | The name a RuleCondition's attr refers to. |
| `label` | `string` | The attribute's name in the routing-rule editor. |
| `help` | `string` | Help text for the attribute in the routing-rule editor. |
| `placeholder` | `string` | Placeholder for the attribute's value in the routing-rule editor. |
